## Description

Oh, it isn't the Sun God Nika this time?

Maybe `helios-d-sun` holds the clue.

## Solve

- Search for `helios-d-sun` either using blackbird or google
- Find the github user, go to the only repo present
- Decode the poem to get the date
- Now yk you need to find this date somewhere
- You can get email id of the commit user, by adding `.patch` behind url
- Either use an osint tool (much easier and obvious option when you just have email) or just go to google calendar (cause yk you have a date and email), and the calendar is public
- So just go to June 21st 2026 for the flag
